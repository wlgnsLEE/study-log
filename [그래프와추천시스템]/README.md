# 그래프와 추천 시스템

그래프 이론을 바탕으로 추천 시스템의 핵심 개념과 모델을 학습한다.  
강의 노트를 정리하고, CS224W 학습 이후 관련 내용을 코드로 실습할 예정이다.

## 학습 내용

| 순서 | 주제                      |
| :--- | :------------------------ |
| 1    | 그래프와 추천 시스템 개요 |
| 2    | 그래프의 패턴 분석        |
| 3    | PageRank                  |
| 4    | 정보 확산과 Cascade       |
| 5    | 커뮤니티 탐지             |
| 6    | 기본 추천 시스템          |
| 7    | Node Embedding            |
| 8    | 고급 추천 시스템          |
| 9    | Graph Neural Network 기초 |
| 10   | Graph Neural Network 심화 |

## 학습 현황

| 자료                                                                 | 핵심 내용                                                                                                                                          |
| :------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------- |
| [1. introduction](./Notes/%5BGraph%5D%201.%20introduction.pdf)       | 복잡계의 상호작용을 그래프로 표현하는 이유와, 정점·링크·그래프 수준의 대표적인 그래프 머신러닝 과제를 익혔다.                                      |
| [2. patterns](./Notes/%5BGraph%5D%202.%20patterns.pdf)               | 실제 그래프가 무작위 그래프와 달리 작은 세상 효과, 두터운 꼬리의 차수 분포, 거대 연결 요소와 높은 군집 계수를 보인다는 점을 이해했다.              |
| [3. pagerank](./Notes/%5BGraph%5D%203.%20pagerank.pdf)               | 임의 보행 관점에서 링크 구조로 정점의 중요도를 계산하고, 감쇠 계수와 순간이동으로 스파이더 트랩과 막다른 정점 문제를 해결하는 PageRank를 학습했다. |
| [4. cascade](./Notes/%5BGraph%5D%204.%20cascade.pdf)                 | 정보·행동·고장의 전파를 독립 전파 모형과 선형 임계치 모형으로 설명하고, 탐욕 알고리즘으로 영향력 최대화 시드 집합을 찾는 방법을 익혔다.            |
| [5. community](./Notes/%5BGraph%5D%205.%20community.pdf)             | 내부 연결이 밀집한 커뮤니티의 정의와 탐색 문제를 이해하고, 확률적 커뮤니티 모형과 중첩 커뮤니티를 다루는 방법을 학습했다.                          |
| [6. recommend_basic](./Notes/%5BGraph%5D%206.%20recommend_basic.pdf) | 상품·사용자 프로필의 유사도를 쓰는 내용 기반 추천과 취향이 비슷한 사용자를 활용하는 협업 필터링, 그리고 MSE·RMSE 기반 평가를 익혔다.               |
| [7. node_embedding](./Notes/%5BGraph%5D%207.%20node_embedding.pdf)   | 인접성·경로·이웃 중첩·임의 보행으로 정점 유사도를 정의하고, DeepWalk·node2vec으로 정점 임베딩을 학습하는 방식을 이해했다.                          |
| [8. recommend_adv](./Notes/%5BGraph%5D%208.%20recommend_adv.pdf)     | 사용자와 상품의 잠재 요인을 행렬 분해로 학습하고, 정규화·편향·시간 정보를 반영해 추천 정확도를 높이는 방법을 익혔다.                               |
| [9. gnn_basic](./Notes/%5BGraph%5D%209.%20gnn_basic.pdf)             | 이웃 정점의 정보를 반복 집계하는 귀납식 표현 학습으로서 GNN의 구조·학습·활용을 이해하고, GCN과 GraphSAGE를 학습했다.                               |
| [10. gnn_adv](./Notes/%5BGraph%5D%2010.%20gnn_adv.pdf)               | GAT와 그래프 수준 표현 학습을 다루고, 지나친 획일화와 그래프 데이터 증강처럼 기본 GNN의 한계를 보완하는 방법을 익혔다.                             |
