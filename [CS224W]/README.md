# CS224W: Machine Learning with Graphs

Stanford CS224W 강의를 통해 그래프 머신러닝의 기초부터 응용까지 학습한다.
강의 노트, 과제, Colab 실습을 함께 정리한다.

## 학습 내용

- 그래프 머신러닝 소개
- 전통적인 머신러닝 기반 그래프 분석
- Node Embedding
- Graph Neural Network
- 그래프 기반 예측과 추천 시스템 응용

## 학습 현황

| 자료                                               | 핵심 내용 요약                                                                                                                                                                                                                                                                    |
| :------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [01-intro.pdf](./Notes/01-intro.pdf)               | 그래프는 관계와 상호작용을 표현하는 언어이며, 문제에 맞는 노드·간선 정의와 그래프 표현 방식이 예측 성능을 결정한다.                                                                                                                                                               |
| [02-tradition-ml.pdf](./Notes/02-tradition-ml.pdf) | 노드·링크·그래프 수준의 수작업 특성을 설계해 기존 ML 모델에 적용하며, Graphlet과 WL kernel로 그래프 전체의 구조를 비교한다.                                                                                                                                                       |
| [03-nodeemb.pdf](./Notes/03-nodeemb.pdf)           | 랜덤 워크로 노드 유사도를 정의하고 DeepWalk·node2vec의 임베딩을 학습해, 특성 공학 없이 다양한 다운스트림 과제에 활용한다.                                                                                                                                                         |
| [04-pagerank.pdf](./Notes/04-pagerank.pdf)         | PageRank는 중요한 노드에서 받은 링크를 더 크게 반영해 정점의 중요도를 계산하며, 임의 보행의 정상 분포를 멱 반복법으로 구한다.<br>순간이동을 도입해 막다른 정점과 스파이더 트랩을 해결하고, Personalized PageRank·Random Walk with Restart으로 특정 정점과 가까운 노드를 추천한다. |
| [05-message.pdf](./Notes/05-message.pdf)           | 일부 라벨만 주어진 그래프에서 이웃 노드의 상관관계를 활용해 미지 노드의 라벨을 함께 추론하는 반지도 노드 분류를 다룬다.<br>Relational Classifier·Iterative Classifier·Belief Propagation을 소개한다.                                                                              |
| [06-GNN1.pdf](./Notes/06-GNN1.pdf)                 | Shallow Embedding의 한계(transductive·노드 특성 미활용)를 넘어, 이웃의 메시지를 집계하는 다층 GNN으로 노드 표현을 학습하는 원리를 다룬다.<br>GCN의 평균 집계와 GraphSAGE의 유연한 집계 함수를 학습하고, 지도·비지도 목적 함수로 모델을 훈련하는 방식을 익힌다.                    |
| [07-GNN2.pdf](./Notes/07-GNN2.pdf)                 | 메시지 계산과 집계를 일반화해 GCN·GraphSAGE·GAT를 비교하고, 어텐션과 다중 헤드로 이웃별 중요도를 학습하는 방법을 다룬다.<br>과도한 층 적층에 따른 over-smoothing을 skip connection으로 완화하는 원리를 소개한다.                                                                  |
