# CS224W: Machine Learning with Graphs

Stanford CS224W 강의를 통해 그래프 머신러닝의 기초부터 응용까지 학습한다.
강의 노트, 과제, Colab 실습을 함께 정리한다.

## 학습 내용

- 그래프 머신러닝 소개
- 전통적인 머신러닝 기반 그래프 분석
- Node Embedding
- Graph Neural Network
- 그래프 기반 예측과 추천 시스템 응용

## 디렉터리 구조

```text
.
├── Notes/    # 강의별 학습 노트와 자료
├── Assign/   # 과제 및 풀이 기록
└── Colab/    # 실습용 Colab 노트북
```

## 학습 현황

| 자료                                               | 핵심 내용 요약                                                                                                              |
| :------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------- |
| [01-intro.pdf](./Notes/01-intro.pdf)               | 그래프는 관계와 상호작용을 표현하는 언어이며, 문제에 맞는 노드·간선 정의와 그래프 표현 방식이 예측 성능을 결정한다.         |
| [02-tradition-ml.pdf](./Notes/02-tradition-ml.pdf) | 노드·링크·그래프 수준의 수작업 특성을 설계해 기존 ML 모델에 적용하며, Graphlet과 WL kernel로 그래프 전체의 구조를 비교한다. |
| [03-nodeemb.pdf](./Notes/03-nodeemb.pdf)           | 랜덤 워크로 노드 유사도를 정의하고 DeepWalk·node2vec의 임베딩을 학습해, 특성 공학 없이 다양한 다운스트림 과제에 활용한다.   |
